## 核心逻辑

- 周期用量只来自独立服务端账本。按历史增量重建、合并重叠采样，重启不清零；按北京时间及节点重置日切换，校准不跨周期沿用。
- 跨周期或快照超过120秒会失效旧用量和进度条；网络失败时显示待同步，不用网卡计数冒充周期流量。
- 流量条连续填充，短竖线不标今天日期；用量比例超过时间比例使用黄色，配额耗尽使用红色。
- 预测与卡片共用账期、计费方向、校准。完整零用量日计入，缺测日不参与日均；无有效样本不伪造安全预测。
- 详情是同一应用内的原生 dialog，首页 DOM 和滚动位置保持；关闭、返回、Esc、遮罩均收起。
- 流媒体首次安装检测一次，此后管理员手动触发。访客只读；任务绑定节点和租约，worker 仅执行固定检测器，断网补传不重扫。

## 设置按钮

| 按钮/分类 | 实际作用 |
| --- | --- |
| 顶栏视图/外观、统计显示菜单 | 当前浏览器偏好，启用本地存储时才保留。 |
| 管理员主题设置 | 站点默认值；保存后由核心主题设置接口持久化。 |
| 实时预览 | 只影响当前页面草稿；关闭后继续编辑不会改变页面。 |
| 重置 | 确认后将草稿重置为发布默认值，仍需保存。 |
| 导入/导出 | 导入合并已知配置并等待保存；导出当前草稿。 |
| 本期流量重置/校准 | 由核心节点管理和账本控制，不提供无效的主题独立计费按钮。 |
| 流媒体刷新/重新检测 | 访客刷新已保存结果；管理员为已安装在线组件的节点创建检测任务。 |

- TypeScript、ESLint、正式构建和压缩包完整性校验通过。

- 实测关闭详情前后保留同一卡片 DOM 和400px滚动位置；默认标签顺序为预测、流媒体、负载、延迟。
- 本机审查预览对所有远程写操作返回405，主题保存只写进内存；没有通过验证过程触发线上扫描。
- 依赖审计结果为0个已知漏洞；Linux CI 使用同一 npm lock、测试和打包命令复核。

## 适用边界

配套后台已按 Komari 1.2.5 的 SQLite schema 验证，其他版本先预检；不承诺所有核心版本兼容。标准库没有自定义计费列时按每月1日重置。采样缺失的历史不能还原字节，预测不是运营商账单。

新的 systemd 安装器提供 schema 预检和健康等待；本次未在另一台全新 Linux 主机演练完整 root 安装。源数据库及目录必须允许服务账户只读访问。默认是本机14天备份，异地副本另配。

本次交付 GitHub 源码及可安装包，生产站点未自动切换到本审查版。旧的个人节点任务映射需按安装文档迁移；原节点配置、原始累计和现存账本无需重建。
